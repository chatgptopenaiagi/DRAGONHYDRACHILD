# LocalAI architectural inheritance for cognitive V2

The preserved LocalAI system is an engineering ancestor, not disposable legacy. V2 reuses useful concepts while preserving the original files and leaving historical privileged components inactive. No component is removed because it appears complex or redundant.

This review reread surviving source and policy files on 2026-09-26 local time and compared them with the [recovery archaeology](LOCALAI_ARCHAEOLOGY.md), [reconstructed architecture](LOCALAI_RECONSTRUCTED_ARCHITECTURE.md), [earlier ARX notes](LOCALAI_NEXT_GENERATION_ARX_NOTES.md) and [recovery security review](LOCALAI_SECURITY_BOUNDARIES.md). Paths below are evidence identifiers relative to the preserved `C:\LocalAI` tree, not commands or repository links.

**OBSERVED** identifies directly inspected source or a historical manifest statement. **STRONGLY_INFERRED** identifies a conclusion supported by multiple sources. **UNKNOWN** identifies a remaining evidence gap. A historical file proves what was written or recorded; it does not establish current service operation.

## What the tunnel meant

**OBSERVED:** Broker received a prompt plus selected local context, sent bounded chat messages to a configured endpoint and wrote job results. The planner proposed a bounded plan; deterministic code chose the final route; Sentinel reviewed scope; action policy and execution remained separate. MCP called a fixed bridge with discrete arguments and bounded timeout/output.

**STRONGLY_INFERRED:** The owner's AI tunnel referred to restricted context, task routing, role separation and authority boundaries. V2 carries forward those operational properties through ARX projection, local Qwen contracts, independent Codex artifacts and deterministic proposal policy.

**UNKNOWN:** No reviewed source establishes a mechanism that exposes a physical percentage of a model's intelligence. Model size, active experts, quantization, GPU offload and context length are computational choices; none independently grants or removes machine authority.

## Evidence that changes the reuse decision

The Broker source sets `MaxJsonLength=Int32.MaxValue`, reads the complete response stream, and falls back to returning raw text for malformed envelopes. V2 therefore reimplements response validation rather than copying this parser. The early read-only executor accepts whole LocalAI roots and checks the final reparse-point target; V2 provides no generic reader and checks confined artifact paths. The historical build executor performs restore before its atomic execution transition; that sequencing requires revision before any future controlled-build capability.

These are source-level findings, not claims of exploitation. Historical identity/SQL/ACL state is not current-machine proof. The earlier recovery description of parallel manual Ollama/llama work as unowned is superseded by the owner's explicit identification of those processes and the Modelfile as authorized work. Their preservation remains required.

Any future component removal must record a concrete claim, evidence, capability loss, isolated comparison, measured result and reversible replacement before deletion. This V2 block does not authorize such removal. See [security](COGNITIVE_SECURITY_MODEL.md), [routing](QWEN_ROUTING.md) and [ARX](ARX_MACHINE_STATE_FABRIC.md).

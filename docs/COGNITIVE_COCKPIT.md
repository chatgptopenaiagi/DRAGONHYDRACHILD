# Cognitive cockpit

The CHILD dashboard adds cognitive status, machine awareness, world awareness, recent deltas, memory, security and cognitive performance. It reads a fixed bounded `cockpit.json` generated by the explicit cognitive CLI. It grants no Windows, model-launch, SQL-admin or acquisition authority.

`web/child-dashboard/cognitive-status.php` rejects non-loopback callers, bounds input size, rejects unexpected top-level fields and forbidden secret/reasoning keys, and calculates snapshot age at request time. A sample older than 60 seconds displays STALE. The Python policy independently enforces original observation expiry and state-hash equality. Refreshing a browser does not refresh an observation.

`web/child-dashboard/index.php` renders through escaped server text and DOM `textContent`. Existing scientific dashboard and LocalAI status remain. No Joomla core or database migration is required; deployment updates only the isolated CHILD dashboard directory.

## Status semantics

| Field | Meaning |
| --- | --- |
| PINNED_MODEL_EXPECTATION | Known expected model profile, not proof that a backend is currently ready. |
| PROCESS_OBSERVED | A bounded process probe recognized the owned model; independent authenticated gateway health is still required. |
| Gateway authentication | Result from the authenticated loopback client, never a token value. |
| Last cycle / reconciliation | Immutable artifact hashes; absent results remain absent. |
| Machine snapshot age | Actual observation age, not page-render age. |
| World evidence | Accepted CHILD evidence references; original prediction remains a future projection. |
| Learning events | Later-observation comparison records, not changes in model prose. |
| Performance | Cognitive latency/error/abstention/comparison counts; no predictive accuracy claim. |

Owner-authorized ports 11434 and 11435 are labeled separately. A new local listener is a change requiring interpretation, not automatic evidence of hostility. Observability is on-demand in this foundation; no background collector was added for ARX.

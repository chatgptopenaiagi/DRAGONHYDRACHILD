# CHILD architecture scorecard

This scorecard evaluates independent dimensions. It deliberately has no total score. **COMPLETE** describes a specified demonstrated capability, not production readiness. Overall maturity remains **EXPERIMENTAL**; unresolved external and scientific gates remain visible in the [per-version stage evidence](evidence/child-stage-summary.json).

## Roadmap interpretation

The owner override changes execution cadence. It does not make mathematical interfaces, synthetic demonstrations and external success gates equivalent. Every version was attempted; the authoritative requirement/gate states are maintained in the [V0–V10 matrix](CHILD_V0_V10_COMPLETION_MATRIX.md) and its [machine-readable stage summary](evidence/child-stage-summary.json).

| Version | Demonstrated architectural contribution | Gate still requiring honest qualification |
| --- | --- | --- |
| V0 | Independent Python 3.14 CHILD runtime, two isolated databases, bounded identities, GPU diagnostics and local web health | Existing-machine validation is not a clean-machine bootstrap |
| V1 | Approved public fixture capture, deterministic validation, append-oriented CHILD SQL, MariaDB presentation and separate Joomla/XAMPP surface | Desktop IAB success remains unavailable; successful bounded CLI acquisition is a distinct producer |
| V2 | Generic bounded acquisition contract, fixture adapter, actual prospective captures and second weather provider | Weather is a London forecast proxy, not independent fixture corroboration; real odds absent; sustained multi-day scheduler record pending |
| V3 | Time-correct feature calculation, lineage, missingness, exact replay and bounded JSON analytical export | No lineup/injury/real-market feature evidence; DuckDB/Parquet are not activated without measured need |
| V4 | Seven comparable methods, permanent empirical baselines, Poisson GLM, rating model and KNN; optional NumPy/PyTorch batch experiment | No demonstrated prospective superiority, convergence guarantee for fixed-iteration GLM or reason to add external math runtimes |
| V5 | Exact independent/corrected matrices, explicit tail mass, conditional mixtures and seeded Monte Carlo | Scenario parameters remain hypotheses; no validated injury/weather model or full uncertainty decomposition |
| V6 | Equal-weight and strictly past-score-weighted ensembles, disagreement and calibration output | Adaptive ensemble did not achieve lowest sample loss; no validated stacking advantage |
| V7 | Real typed market math, temporal querying and provenance-preserving quote trajectories | Lawful real odds acquisition and actual market comparison remain BLOCKED |
| V8 | Bounded ResearchNeed ranking, validation/recalculation, measured controlled entropy and completeness changes | Real acquisition-driven forecasting improvement is unproven |
| V9 | Chronological proper-score comparisons, ablation, date-block sensitivity and immutable prospective ledger | Future actual outcome has not been observed; continuous historical/prospective performance history is not yet mature |
| V10 | Thirteen logical capability records with source, failure, maturity and test metadata | Registering unsupported player, injury, lineup, tactical or odds heads does not make them operational |

Before treating advanced modeling as the main path, retain the practical gates: sustained prospective evidence, working baseline comparisons and demonstrated fresh-machine reproducibility. The baseline-comparison gate has direct evidence. Initial capture and exact replay are strong narrower results; they do not substitute for the remaining duration and deployment evidence.

No component is recommended for deletion merely because a smaller application is possible. The first evidence-based simplification candidate is the KNN form/rest/congestion bundle, whose additional predictive value was negative in this one sample; confirm on a separately declared evaluation before retiring it. Do not expand GPU use for single-match inference, or install extra storage/math technologies, based on architectural availability alone.

Useful next expansion is evidence rather than another framework: genuine repeated daily capture, verified kickoff semantics, later scoring of frozen predictions, a lawful real odds source, and a bounded real information-gap experiment with recorded before/after forecasts. Each would resolve a specific uncertainty in this scorecard.
